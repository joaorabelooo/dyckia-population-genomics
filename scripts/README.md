# Analysis scripts

This directory is reserved for custom scripts used in the final population genomic analyses and figures. The analytical scripts have not yet been deposited. This repository is being assembled and is not a complete reproducibility release.

## Planned contents

- Sample metadata, filtering steps and definitions of the two SNP panels.
- PCA, ADMIXTURE cross-validation and replicate comparison.
- Population diversity, rarefied allelic richness, AMOVA and pairwise FST.
- Spatial analyses and isolation-by-distance tests.
- Outlier analyses using pcadapt, fsthet, BayeScan and LFMM2, including environmental predictor selection and relevant settings.
- SNP identifier harmonization, intersections among methods, population allele frequencies and positional gene annotations.
- Final figure and table generation scripts, with required small input files.

Scripts will be checked against the final manuscript and the versions actually executed on the cluster. Each workflow should document inputs, outputs, software versions, parameters and random seeds where applicable. Historical input identifiers containing VIGA correspond to the manuscript locality CONG.

Raw sequencing reads are archived externally and will not be duplicated here. Temporary files, credentials, large alignment files, obsolete plot variants and saved R workspaces are excluded.
